职业与技能

职业决定小猪的发展方向，每个职业拥有独特的技能体系。技能效果由技能等级、职业等级、属性和八维等级共同驱动。

职业体系

职业按职系组织，每条职系从起源到终极形成完整的成长链。

职系与阶位

每条职系包含7个阶位：

阶位 名称 说明
Tier 0 起源职业 初始身份（如"小猪"），互斥，只能持有一个
Tier 1 基础职业 入门职业，可多持
Tier 2 进阶职业 进阶方向，可多持
Tier 3 分支点 分支起点，此后职业锁定方向
Tier 4 高级职业 延续分支方向
Tier 5 进阶高级职业 继续深入分支路线
Tier 6 终极职业 职系顶端

互斥规则（isExclusive 布尔机制）

  • 所有 isExclusive: true 的职业属于同一个互斥组
  • 已持有任意 exclusive 职业时，无法再持有其他职系的 exclusive 职业
  • 同职系内 exclusive 职业不互斥，通过 prerequisites 前置链自然串成升级链
  • 新增职系只需在分支点及之后标记 isExclusive: true，自动加入互斥组

tier 0-2 的职业 isExclusive: false，可多持，不冲突。

技能系统

转职即获得该职业的全部技能，技能初始1级，职业激活时所有技能同时生效。

技能类型

类型 生效场景 说明
被动技能 永久 永久生效，提供属性加成、经验加成等常驻效果，scope 可选 life/combat/both
主动技能 战斗外 战斗外手动使用，消耗能量，有冷却时间。效果包括获得道具、全局增益等
战斗主动 战斗中 战斗中自动或按策略释放，有冷却回合。包含普通攻击和技能攻击，使用 damageFormula 计算伤害
战斗辅助 战斗中 战斗中生效，提供 buff/debuff/护盾 等辅助效果，可影响范围内友方或敌方
领域技能 战斗中 按位置或条件触发的强化效果，同名领域前三名起效，效果递减（100%/60%/30%）

技能升级

技能等级独立于职业等级，成长规则如下：

  • 转职获得职业时，所有技能初始为 1级
  • 技能最高 40级
  • 职业等级每提升 20级，随机 1个技能提升1级

技能升级是随机的，同一职业的技能可能以不同速度成长。小猪转生后技能等级不会重置。

技能效果系数

技能效果由多个维度共同决定：

维度 说明 来源
技能等级 技能独立等级，1-40 职业每20级随机+1
职业等级 职业等级 职业经验积累
属性 八维属性值 力量/耐力/敏捷/灵巧/智力/感知/意志/魅力
八维等级 八维属性等级 八维经验积累

不同技能使用不同的系数公式，具体效果由技能配置决定。

领域技能排名

同名领域技能在战斗中按效果排名递减，排名由技能等级决定：

排名 效果比例
第1名 100%
第2名 60%
第3名 30%
第4名及以后 不起效

领域技能通常带有 triggerCondition 触发条件（如位置前/中/后排、hp低于30%、击杀触发等），满足条件时才生效。

能量系统

主动技能（战斗外使用）消耗能量，能量系统包含以下公式化字段：

  • energyFormula：当前能量值（基础）
  • energyMaxFormula：能量上限
  • energyCostFormula：单次使用消耗
  • regenRateFormula：每小时恢复量

所有能量数值均以公式字符串存储，支持变量 $level / $jobLevel / $attribute 等。固定值也是公式（如 "100"）。未来可接入季节/天气/节律等外部变量。

能量每小时固定恢复，升级可能提升上限或减小消耗。

战斗范围与目标

所有战斗类型技能（战斗主动、战斗辅助、领域）共用统一的 target 和 range 字段：

字段 取值 说明
target
（目标选择）		 self 只影响自己
single 单体目标
aoe 范围群体
all_allies / all_enemies 全体友方 / 全体敌方
range
（作用距离）		 melee 近战（贴身）
ranged 远程
adjacent 周围（邻格）
column / row 同列 / 同排
all 全场

转生与职业

转生时职业和技能的处理：

  • 职业等级和技能等级保留，但职业变为不激活状态（不生效）
  • 重新转职已拥有的休眠职业即可激活，职业等级和技能等级恢复生效，无需重新升级
  • 起源职业重置为"小猪"
